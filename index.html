How to Use the System

Reminder

Please be reminded: This system stores all data inside the browser's cache only. It does not connect to any server and can be used offline. Clearing your browser storage or using a different device/browser will remove the stored data.

Templates

You can find the required Attendees and Prizes templates inside the project folder.

For easier editing and formatting, open the templates using:

  • Microsoft Excel, or
  • Google Sheets (upload the file to Google Drive)

Make sure to follow the column format exactly to avoid loading errors.

1. Setting Up Attendees and Prizes

Upload the Attendees and Prizes templates. Make sure they are filled correctly and uploaded to the correct sections.

Click the "Load & Cache" (purple) button to load the data.

You will see:

  • A list of prizes in the Prizes List
  • Counts of attendees, prizes, and winners in the Cache Info tab (scroll to bottom)

2. Setting Up the Background

In the Setup Background section, select an image file. If successful, it will appear automatically.

Reset Buttons

  • Clear Background – removes background image
  • Clear All Cache – clears attendees and prizes from memory
  • Reset Prize Draw Counts – removes winners and resets draw progress

Page Auto Reload – toggles automatic page refresh for updating lists.

3. How to Draw a Raffle

Single Draw
  • Draws one winner at a time
  • Shows Claim and No Show buttons
  • Claim saves winner
  • No Show redraws a new winner
Batch Draw
  • Automatically draws winners until prize limit is reached
  • Winners are saved automatically
Next Prize
  • Moves to the next prize and draws using current draw mode

4. Exporting Winners List

Go to the Winners List section → click Export Winners to download a CSV of winners.

5. Draw Screen Keyboard Controls

  • ENTER –Start Draw
  • SPACEBAR – Start Draw Animation
  • C – Claim Winner
  • N – No Show / Redraw
  • TAB – Switch Draw Mode (Single / Batch)
  • BACKSPACE – Open Configuration Screen
  • H – Show/Hide On-Screen Controls
