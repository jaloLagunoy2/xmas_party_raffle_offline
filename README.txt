Christmas Raffle v6 - Fixed

This version merges previous v6 features with fixes:
- Restored missing buttons (Reset, Clear Cache, Export Winners, Single/Batch Draw)
- Sequence column displays correctly
- Draw counts update on the prize table after each claim/batch
- Winners stack in the draw tab and are added to winners list
- Parent window listens to messages from draw tab to update display when draws happen

How to use:
1. Open index.html in a browser
2. Upload attendees.csv and prizes.csv, then click 'Load & Cache'
3. Click 'Single Draw' or 'Batch Draw' to open draw in new tab
4. Claim or No Show as needed; use Next to proceed
5. Export winners or clear/reset cache as needed
